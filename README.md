# Krishna Spiritual AI

Static 3D character viewer with pale blue skin, crown, earrings, peacock feathers and red tilak. Preserves the existing face, expression controls, speech animation and cursor tracking.

Preview locally: `python3 -m http.server 8876`

Cloudflare Workers serves the repository using `wrangler.jsonc`. Embed with `?embed=1`. Models use gzip and meshopt compression; the cover is captured from the current viewer.
